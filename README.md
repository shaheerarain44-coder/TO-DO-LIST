# To-Do List App 📚

A simple To-Do List application built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Demo](YOUR-LIVE-DEMO-LINK)

## ✨ Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Press Enter to add a task
- Simple and clean design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📌 About

This project was created to practice JavaScript DOM manipulation, events, 
creating elements, and removing elements.
